# v0.1 plan — Foundation

Status: draft, 2026-10-13. Lane: **Critical** (money, persisted member data, install path).
Done-when, from the spec: installed from scratch on a clean machine in one command; 50 test members on
recurring dues cycle through a month on a Stripe test clock; export produces every table; audit log
shows every staff write.

## Scope

In: Space, Person, Membership class, Membership, Credential (record only, no hardware), roles, audit
log, Stripe Billing subscriptions with test-clock support, offline payment record, full CSV/JSON export,
Docker Compose install, automatic migrations, nightly backup command with tested restore, staff screens
for the above, member screen for "my membership and next charge".

Out: documents, badges, resources, bookings, ledger beyond dues, classes, access hardware, reports,
importers, email beyond transactional. Each has its own version.

## Units (each a branch, each reviewed before merge)

1. **Skeleton.** Django project, Postgres, Redis, Compose file, `make install` / one script that brings
   it up on a clean Ubuntu box, settings from environment, health endpoint. Proof: fresh VM, one command,
   login page.
2. **Core models.** Space, Person, MembershipClass (seeded from `docs/research/proximity-lpm-space-config.json`
   with the field list in spec §5), Membership, Credential, Role scopes. Migrations. Admin. Proof: the
   seventeen LPM classes load and render.
3. **Audit log.** Middleware that records every staff write with before/after. Proof: a test that fails
   when a model is added without audit coverage.
4. **Stripe dues.** Connect account link, customer and subscription per membership, webhook ingestion,
   grace period, inactive-on-overdue state flip. Stripe test clocks in CI. Proof: 50 synthetic members
   advanced one month; invoices, states and totals match Stripe to the cent.
5. **Offline payments.** Staff records cash or check against a membership. Proof: reconciliation report
   equals Stripe plus offline.
6. **Export.** Every table to CSV and JSON by an owner, streamed, with a manifest and row counts.
   Reimport of the export into a fresh install reproduces the row counts. Proof: round-trip test.
7. **Backup and restore.** Nightly `pg_dump` plus media to a configurable target; `restore` command.
   Proof: restore on a fresh machine under 15 minutes, documented with timings.
8. **Member and staff screens.** Minimum screens for the above, responsive. Proof: newcomer walkthrough
   on every screen before the version is called done.
